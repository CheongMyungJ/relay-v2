# 설정의 모델 선택지는 엔진별 고정 목록이다

## 규칙
- 설정 화면(기본 모델, 상세 설정의 단계별 모델)의 모델 선택지는 `app/src/shared/agent.ts`의 `AGENT_MODELS` 고정 목록에서만 고른다. CLI의 내부 캐시를 읽거나 직접 입력을 받지 않는다.
- 모델마다 받는 추론 수준을 목록에 함께 둔다. 화면·저장 검사·실행 해석이 이 목록 하나를 같이 쓴다.
- 새 모델이 나오면 이 목록을 고친다. Codex 목록에는 gpt-6.1-sol을 넣는다(2026-10-06 사람이 알려 줌).
