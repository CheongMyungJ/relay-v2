# 앱 업데이트는 사람이 설치를 확인한 뒤에만 앱을 끝내고 설치한다

## 규칙
- 업데이트 설치를 위해 앱을 끝내는 것은 사람이 설치를 확인한 뒤에만 한다. 사이드바의 업데이트 버튼을 누르면 새 버전을 바로 확인하고 받으며, 받기가 끝나면 앱을 끝내고 설치한다는 확인을 받는다. 취소하면 앱을 그대로 쓰고, 받아 둔 버전은 앱을 끝낼 때 설치된다(`docs/implementation.md`의 I95, I121).
- 업데이트 버튼은 사이드바 아래 [설정] 오른쪽에 아이콘으로 두고, 실행 중인 앱의 버전은 좌상단 relay 아이콘과 relay 글자 오른쪽에 보인다.
- 앱에서 직접 설치할 수 없는 환경(WSL 등, D379)은 설치 명령을 보이는 수동 설치 안내를 그대로 쓴다.
