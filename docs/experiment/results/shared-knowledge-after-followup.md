# 확인된 보고서 업무 규칙

- 적용 범위: 센서 관측의 평균·중앙값·최댓값 보고서.
- 규칙: `null`은 관측 누락이므로 집계와 표본 수에서 제외한다. 남은 관측이 하나도 없으면 결과는 `null`이다. 숫자 0은 실제 관측으로 포함한다.
- 사람 답변 근거: “보고서 업무 규칙: null은 관측 누락이므로 집계에서 제외한다. 남은 관측이 하나도 없으면 결과는 null이다. 숫자 0은 실제 관측이므로 포함한다. 평균·중앙값·최댓값 보고서에 공통으로 적용한다.” 후속 답변: “누락으로 제외하는 값은 null이다. undefined와 NaN에 대한 업무 규칙은 모른다.”
