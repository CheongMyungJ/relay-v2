먼저 사람이 정할 것: C2를 어떻게 할지(아래 "남은 설계 논의" 1번). 정하지 않고 다음 세션을 시작하면 아래 프롬프트(규칙은 그대로 두고 표본을 늘려 다시 재기)로 간다.
