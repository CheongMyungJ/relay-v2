## 앱의 requirements 기능 구현 PR(지침 채택과 나란히 시작할 수 있다)

지침 문구는 바꿔 끼울 수 있게 나눠 두었다: 조립(`skills/extract/run.mjs`, `load.mjs`의 `loadLayers`), 규칙 표(`rules.mjs`), 정적 검사(`check.mjs` [6], [6b])는 판과 상관없다. 구현 PR은 이것을 앱에 붙이고, 넘기는 지시 판은 채택한 판이 정해질 때까지 설정으로 고를 수 있게 둔다(기본값은 사람이 정한다). 시작 전에 아래 설계 논의의 1~5번을 사람과 정한다.
