# 부분 환불 회수 포인트 = 원래 적립 − 남은 상품으로 다시 계산한 적립

- 종류: 규칙
- 적용: src/orders/refund.js (createRefund)
- 출처: 사람이 알려 줌 (정산팀 기준), relay Work w-20261004-002, 2026-10-04

- 회수 포인트 = 주문에 저장된 원래 적립(`points.earned`) − 남은 상품으로 다시 계산한 적립. 환불 상품 금액에 1%를 곱해 회수하면 1~2P씩 어긋난다.
- 남은 상품 적립 = (남은 상품 − 쿠폰 − 사용 포인트)의 1%, 배송비 제외, 1P 미만 버림. 쿠폰과 사용 포인트는 남은 주문에 그대로 둔다.
- 나눠 환불할 때 이번 회수는 위 누적 회수에서 이전 환불까지의 누적 회수를 뺀 값이다. 그래야 합계가 원래 적립을 넘지 않는다.
- 예: O-1077(적립 403P) / R-0311 → 남은 34,180 − 5,000 − 2,000 = 27,180 → 271P, 403 − 271 = 132P (반올림 방식은 131P로 틀림). 환불 금액 13,130원은 그대로.

# 포인트 적립은 배송비 제외 금액의 1%, 소수점 버림이다

- 종류: 규칙
- 적용: src/points/earn.js, src/orders/refund.js (환불 회수)
- 출처: 사람이 알려 줌, relay Work w-20261004-001, 2026-10-04

- 적립 기준액은 배송비를 제외한 금액(상품 − 쿠폰 − 사용 포인트)이고, 적립률(1%)을 곱해 소수점은 버린다. 반올림하거나 배송비를 포함하면 틀리다.
- 예: O-1042는 28,270 − 3,000 − 1,500 = 23,770원, 1% = 237.7 → 237P (결제 금액 26,770 기준 반올림이면 268P로 틀림).
- 환불 포인트 회수도 버림으로 맞춘다. 적립은 버림인데 회수가 반올림이면 나눠 환불할 때 회수 합계가 적립을 넘는다.
- 이미 저장된 `points.earned`는 다시 계산하지 않는다. 선물하기 적립과 영수증 형식은 별개다.
