## 목표
CI의 `npm run test:ci`에서 `ci/batch.test.js`가 간헐적으로 실패하는 근본 원인을 찾아 고친다. 실패 로그: `expected report-6 to belong to job-6, got job-5`.

## 비목표
- 시험에 재시도를 붙이거나, skip하거나, 시간 제한을 늘리는 방식의 우회는 하지 않는다.
- 밤 배치의 기능 추가나 구조 변경은 하지 않는다.
- 병렬 실행을 순차 실행으로 되돌려 문제를 피하지 않는다.

## 원하는 결과
밤 배치를 실제와 비슷한 지연으로 돌려도 보고서가 항상 자기 작업(job)과 짝지어진다. 실행 순서나 지연 시간에 따라 결과가 달라지지 않는다.

## 완료조건
- [ ] 재현 절차(`npm run test:ci`를 여러 번 반복 실행)가 더 이상 실패하지 않는다
- [ ] `npm run test:ci`가 통과한다
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] `ci/batch.test.js`에 재시도, skip, 시간 제한 증가를 넣지 않는다
- [ ] 배치 병렬 실행(동시 4개)은 유지하고, 순차 실행으로 되돌리지 않는다
- [ ] 고쳤다는 근거로 `npm run test:ci`를 여러 번 반복 실행한 결과(실행 횟수와 통과 횟수)가 기록되어 있다
- [ ] 원인이 코드 근거와 함께 설명되고, 수정이 그 원인을 직접 해소한다

## 제약
- 간헐적 실패이므로 한 번 통과한 것만으로는 확인되지 않는다. 반복 실행으로 확인한다.
