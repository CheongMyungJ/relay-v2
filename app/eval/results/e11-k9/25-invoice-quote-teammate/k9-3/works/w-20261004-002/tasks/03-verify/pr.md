# fix: 반품 전표 부가세를 줄별 원 단위 버림 합으로 계산

## 요약
반품 전표(CN-0112)의 환불 부가세·합계가 회계팀 규칙과 몇 원씩 어긋나던 것을 고쳤다. 이제 부가세는 과세 줄마다 원 단위 버림 후 합산한다.

## 원인
`creditTotals`가 과세분 합계(17,438)에 `Math.round`를 한 번 적용했다. 줄별 9,236/6,127/2,075의 소수부(.6/.7/.5)가 합쳐져 1,744가 되었고, 규칙값은 923+612+207 = 1,742다.

## 변경
- `src/invoice/vat.js` (신규): `lineVat`/`sumLineVat`. 면세 줄과 영세율은 0
- `src/invoice/credit-note.js`: `creditTotals`가 `sumLineVat`을 사용
- 저장된 `totals`가 있는 전표는 기존대로 재계산하지 않는다. 청구서·견적서, 할인 안분은 건드리지 않았다
