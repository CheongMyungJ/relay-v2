## 목표
아침 요약 메일(전날 알림 모음)이 같은 날 두 통, 가끔 세 통 발송되는 버그의 원인을 찾아 근본적으로 고친다.

## 비목표
- 없음

## 원하는 결과
- 같은 날짜의 요약 메일은 고객에게 한 통만 간다.
- 실제로 발송에 실패한 요약은 재시도로 다시 보내, 하루를 건너뛰지 않는다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] 요약이 한 번 성공적으로 발송된 뒤에는 같은 날 요약이 다시 발송되지 않음을 확인하는 테스트가 있다
- [ ] 요약 발송이 실제로 실패한 경우 재시도로 다시 발송됨을 확인하는 테스트가 있다

## 제약
- (팀 지식 docs/knowledge/delivery/real-failures-must-be-resent.md) 중복 발송을 막으려고 재시도를 끄거나 줄이지 않는다. 실제 실패는 재시도로 다시 보낸다.
- (팀 지식 docs/knowledge/delivery/real-failures-must-be-resent.md) 고친 뒤 "성공 후에는 다시 안 보냄"과 "실제 실패는 다시 보냄"을 둘 다 테스트로 확인한다.
- 증상만 막는 수정(예: 재시도 비활성화, 발송 건너뛰기)은 해결로 보지 않는다.

## 추가 의견
- 요청에 원인 추정은 없음.
