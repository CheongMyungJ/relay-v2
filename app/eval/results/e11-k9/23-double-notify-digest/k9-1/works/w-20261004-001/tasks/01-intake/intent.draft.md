## 목표
일부 고객이 같은 알림을 두 번, 가끔 세 번 받는 문제를 없앤다. 메일 채널에서 더 자주 나타난다. 원인을 찾아 고친다.

## 비목표
- 재시도 기능 자체를 끄거나 재시도 횟수를 줄이는 것
- 알림 템플릿, 채널 라우팅, 조용한 시간대 같은 중복 발송과 무관한 동작 변경

## 원하는 결과
- 같은 알림은 고객에게 한 번만 전달된다. 메일과 푸시 모두 해당한다.
- 실제로 실패한 발송은 지금처럼 재시도로 다시 보낸다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] 같은 알림이 중복 전달되는 경우를 재현하는 테스트가 추가되고, 수정 후 통과한다
- [ ] 발송이 실제로 실패한 경우에는 재시도로 다시 발송된다는 테스트가 통과한다
- [ ] 메일 채널에서도 같은 알림이 한 번만 발송된다는 테스트가 통과한다

## 제약
- 재시도 자체를 끄면 안 된다. 실제로 실패한 발송은 다시 보내야 한다.

## 추가 의견
- 요청에 원인 추정은 없다. 원인은 fix 단계에서 찾는다.
