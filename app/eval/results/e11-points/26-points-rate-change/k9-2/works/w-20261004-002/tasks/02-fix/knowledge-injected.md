# 적립 포인트는 (상품 금액 − 쿠폰 − 사용 포인트)의 1%, 배송비 제외, 1P 미만 버림

## 규칙
- 적립 기준 금액은 상품 금액에서 쿠폰 할인과 사용한 포인트를 뺀 금액이다. 배송비는 넣지 않는다.
- 적립 포인트는 기준 금액의 1%를 1P 미만 버림한다(반올림 아님). 예: O-1042는 23,770원 → 237P.
- 일반 주문 적립은 `src/points/earn.js`의 `earnPoints`가 이 규칙대로 계산한다.

## 아직 규칙을 따르지 않는 곳
- src/gift/gift-points.js: 배송비 포함 결제 금액에 반올림을 쓴다. 사람이 Work w-20261004-001의 범위에서 뺌(2026-10-04)
- src/orders/refund.js:34: 환불 상품 금액 기준으로 반올림해 회수한다. 사람이 Work w-20261004-001의 범위에서 뺌(2026-10-04)

## 바뀐 이력
- 2026-10-04 처음 남김 (Work w-20261004-001)

# 이미 적립된 포인트는 주문에 저장된 값을 그대로 쓴다

## 규칙
- 주문의 `points.earned`는 주문을 만들 때 계산해 저장한 값이다. 영수증, 환불, 포인트 내역은 이 저장값을 쓰고 다시 계산하지 않는다.
- 영수증 글자(`src/format/`)의 출력 형식은 적립 규정이 바뀌어도 바꾸지 않는다.
