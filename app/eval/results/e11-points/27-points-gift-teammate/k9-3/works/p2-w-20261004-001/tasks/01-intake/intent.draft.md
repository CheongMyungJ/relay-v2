## 목표
선물하기 주문 G-0213(`examples/G-0213.json`)의 적립 예정 포인트가 고객센터 계산인 218P로 나오게 한다. 지금은 249P로 나온다.

## 비목표
- 선물 메시지 카드, 받는 사람 정보를 바꾸지 않는다.
- 영수증 글자(`src/format/`)를 바꾸지 않는다.
- 이미 적립된 포인트를 다시 계산하거나 고치지 않는다.

## 원하는 결과
- G-0213의 적립 예정 포인트가 218P이다.
- 같은 상품을 일반 주문으로 샀을 때의 적립 포인트와 같은 방식으로 계산된다.

## 완료조건
- [ ] 재현 절차(G-0213의 적립 예정 포인트 계산)가 더 이상 실패하지 않고 218P가 나온다
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] G-0213 적립 예정 포인트가 218P임을 확인하는 테스트가 있다
- [ ] 선물 메시지 카드, 받는 사람 정보, `src/format/`의 출력은 수정 전과 같다
- [ ] 주문에 이미 저장된 `points.earned` 값을 다시 계산하는 코드는 바뀌지 않는다

## 제약
- (팀 지식 `docs/knowledge/points/stored-points-earned.md`) 이미 적립된 포인트는 다시 계산하지 않고 주문에 저장된 `points.earned`를 쓴다. 적립 계산식이 바뀌어도 저장된 값은 다시 계산하지 않는다.
