# 이미 발행된 청구서는 다시 계산하지 않고 저장된 합계를 쓴다

- 종류: 규칙
- 적용: 발행된 청구서와 저장된 반품 전표의 합계 (`invoiceTotals`, `creditNoteTotals`)

```

# 부가세는 품목 줄마다 원 단위 버림으로 계산해 합산한다

- 종류: 규칙
- 적용: 청구서, 반품 전표, 견적의 부가세 계산 (`src/invoice/total.js`의 `lineVat` 부근)
- 출처: 사람이 알려 줌, relay Work w-20261003-001, 2026-10-03

회계 규정: 부가세 = 품목 줄마다 (할인된 줄 금액 기준) 원 단위 버림, 그 합이 청구서 부가세다. 합계에서 다시 반올림하지 않는다.
예: INV-2031은 줄별 536+633+325+837+310 = 2,641원, 합계 29,079원이다. 합계에 한 번 반올림하면 2,644원(29,082원)이라 틀리다.
면세 줄과 영세율 청구서의 부가세는 0원이다. 청구서, 반품 전표, 견적 모두 같은 규칙을 쓴다. 각자 합계를 계산하니 규칙을 바꿀 때 세 곳을 함께 본다.
```
