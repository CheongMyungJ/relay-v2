# fix: 반품 전표 부가세를 공용 lineVat으로 계산하고 Q-0457 견적 합계 테스트 추가

## 요약
견적 Q-0457의 합계 문의(56,280원 vs 경리 56,278원)를 확인했다. 현재 코드의 견적 합계는 이미 56,278원이다. 같은 규칙을 쓰는 반품 전표의 부가세가 깨져 있어 공용 `lineVat`으로 맞추고, Q-0457 회귀 테스트를 추가했다.

## 원인
- 56,280원은 4307e8a 이전의 합계 단위 부가세(과세 합 35,891원의 10% = 3,589원)에서 나온 값이다. 4307e8a가 줄마다 버림으로 바꿔 견적은 이미 3,587원이다.
- 머지 뒤 `credit-note.js`가 import되지 않은 `VAT_RATE_PERCENT`를 참조해 ReferenceError가 나고 반품 전표 테스트 5건이 실패했다.

## 변경
- `src/invoice/credit-note.js`: 부가세를 `sumWon(rows.map(lineVat))`로 계산한다(면세 줄·영세율 0원).
- `test/quote.test.js`: Q-0457 합계 테스트(supply 52,691 / vat 3,587 / total 56,278, 면세 줄 BK-1680 부가세 0원) 추가.
- `docs/knowledge/`: 견적 번호·유효 기간 규칙, import 누락 실패 유형 추가.
- 견적 코드, 번호 형식·유효 기간, 발행된 청구서·저장된 합계는 바꾸지 않았다.
