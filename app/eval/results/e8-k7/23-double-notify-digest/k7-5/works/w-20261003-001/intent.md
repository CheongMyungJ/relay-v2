## 목표
같은 알림이 일부 고객에게 두 번, 가끔 세 번 발송되는 버그를 고친다. 메일 채널에서 더 자주 발생한다.

## 비목표
- 재시도 기능 자체를 끄거나 재시도 횟수를 줄이는 것
- 새 채널이나 새 기능 추가
- 이번 버그와 무관한 리팩터링

## 원하는 결과
- 하나의 알림은 고객에게 한 번만 전달된다. 메일과 푸시 모두 해당한다.
- 실제로 실패한 발송은 지금처럼 다시 시도되어 결국 전달된다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다 (같은 알림이 중복 발송되지 않는다)
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] 발송이 실제로 실패한 경우에는 재시도로 다시 발송된다는 것을 확인하는 테스트가 있고 통과한다
- [ ] 중복 발송을 재현하는 회귀 테스트가 추가되어, 수정 전에는 실패하고 수정 후에는 통과한다

## 제약
- 재시도 정책(`src/retry/`)은 유지한다. 실패한 발송의 재발송을 막으면 안 된다.

## 추가 의견
- 요청에는 원인에 대한 사람의 추정이 없다.
