# fix: 느리지만 성공한 발송을 시간 초과로 보고 다시 보내던 문제 수정

## 요약
같은 알림이 2~3번 전달되던 버그를 고친다. 메일처럼 응답이 느린 채널에서 더 잦았다.

## 원인
발송이 성공해도 걸린 시간이 제한 시간을 넘으면 시간 초과로 보고 재시도했다. `src/retry/policy.js`의 `decide()`가 시간 검사를 성공 판정보다 먼저 했고, 요약 경로의 `withDeadline()`은 성공 뒤에도 `SendTimeoutError`를 던졌다.

## 변경
- `decide()`: 성공이면 걸린 시간과 상관없이 `done`.
- `withDeadline()`: 성공이면 던지지 않고 `slow`만 반환, `runner.js`는 경고 로그만 남김.
- 실패한 발송의 재시도(시간 초과 오류 포함)는 그대로다.
- `docs/knowledge/`에 팀 지식 2건 추가.

## 테스트
- `npm test`: 79개 전부 통과.
- 중복 재현 테스트 3건은 수정 전 실패, 수정 후 통과. 실패한 발송의 재시도 보존 테스트 2건 추가.
- 남은 위험: 진짜 시간 초과 오류 뒤 재시도의 중복 가능성(멱등 키 없음), 요약 수동 재실행.
