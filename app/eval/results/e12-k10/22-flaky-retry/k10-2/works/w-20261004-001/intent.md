## 목표
CI 전용 시험 `ci/batch.test.js`가 가끔 `expected report-6 to belong to job-6, got job-5`로 실패하는 원인을 찾아 고친다. 지금은 job과 report가 어긋나 보고서가 다른 job에 속하게 되는 간헐적 오류다.

## 비목표
- 시험에 재시도를 붙이거나, skip하거나, 시간 제한을 늘리는 것 (해결이 아님)
- 시험 기대값을 바꿔 실패를 가리는 것

## 원하는 결과
- 밤 배치를 실제와 비슷한 지연으로 돌려도 report-N은 항상 job-N에 속한다.
- 지연 시간이 달라져도 결과가 같아, `npm run test:ci`가 재실행 없이 안정적으로 통과한다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다
- [ ] `npm test`와 `npm run test:ci`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] `ci/batch.test.js`를 여러 번 연속 실행해도(예: 20회) 모두 통과한다
- [ ] 시험에 재시도, skip, 시간 제한 증가가 추가되지 않았다

## 제약
- 시험이 아니라 원인이 되는 코드를 고친다.

## 추가 의견
- 로컬 `npm test`는 늘 통과하고 CI 전용 시험만 가끔 실패한다. 재실행하면 통과한다.
