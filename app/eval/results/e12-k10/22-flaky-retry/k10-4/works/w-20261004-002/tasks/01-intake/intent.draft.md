## 목표
CI 전용 시험 `ci/archive.test.js`가 간헐적으로 실패하는 문제를 고친다. 밤 배치 뒤 보고서가 보관소에 온전히 남아야 하고, 그 결과가 실행 때마다 달라지지 않아야 한다.

## 비목표
- `ci/batch.test.js`의 간헐 실패는 따로 고쳐서 리뷰 중이므로 이번 범위가 아니다.

## 원하는 결과
- `npm run test:ci`에서 `ci/archive.test.js`가 반복 실행해도 늘 통과한다.
- 실패 때 나타나던 증상이 사라진다: `ENOENT: 파일이 없습니다: reports/2026-09/.<임의>.tmp`, `report-N 보관본의 고객사가 다르다`(예: wayne, stark여야 함).
- 로컬 `npm test`는 계속 통과한다.

## 완료조건
- [ ] 재현 절차(`npm run test:ci`를 반복 실행)가 더 이상 실패하지 않는다
- [ ] `npm test`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] `npm run test:ci`가 통과한다
- [ ] 실패 조건(조회와 저장 지연이 겹치는 경우)을 결정적으로 재현하는 회귀 시험이 `npm test`에 추가되어 있고, 수정 전 코드에서는 실패하고 수정 후에는 통과한다
- [ ] 배치의 병렬 실행(동시 4개)이 유지된다(순차 실행으로 되돌리거나 동시 실행 수를 줄이지 않는다)
- [ ] `ci/archive.test.js`를 연속 20회 반복 실행한 결과가 기록되어 있고, 20회 모두 통과한다
- [ ] 시험의 재시도, skip, 시간 제한 늘리기, 지연 설정 줄이기 없이 통과한다

## 제약
- (팀 지식 docs/knowledge/testing/flaky-test-policy.md) 간헐 실패 시험은 재시도, skip, 시간 제한 늘리기, 지연 설정 줄이기로 가리지 않는다. 제품 동작의 원인을 찾아 고치고, 실패 조건을 결정적으로 재현하는 회귀 시험을 `npm test`에 추가한다.

## 추가 의견
- 요청 정보: 로컬 `npm test`는 늘 통과하고, CI에서 재실행하면 통과한다. 실패 로그는 실행마다 조금씩 다르다.
