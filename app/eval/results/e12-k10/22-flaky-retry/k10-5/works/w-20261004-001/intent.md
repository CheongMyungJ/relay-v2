## 목표
CI 전용 시험 `ci/batch.test.js`(밤 배치를 실제와 비슷한 지연으로 실행)가 가끔 `expected report-6 to belong to job-6, got job-5`로 실패하는 문제의 근본 원인을 찾아 고친다.

## 비목표
- 시험에 재시도를 붙이거나, skip하거나, 시간 제한을 늘리는 방식의 우회(사람이 해결이 아니라고 명시함)
- 이번 실패와 관계없는 기능 추가나 구조 개편

## 원하는 결과
지연 시간이나 실행 순서가 달라져도 각 report가 자기 job에 올바르게 대응한다. `ci/batch.test.js`가 재실행 없이 안정적으로 통과한다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다
- [ ] `npm run test:ci`가 통과한다 (로컬 `npm test`도 통과한다)
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] `ci/batch.test.js`를 여러 번 반복 실행해도(지연 순서가 바뀌어도) `report-N`이 `job-N`에 속하지 않는 실패가 나오지 않는다
- [ ] `ci/batch.test.js`에 재시도, skip, 시간 제한 증가를 넣지 않는다

## 제약
- 시험을 느슨하게 만들지 않고 제품 코드의 원인을 고친다.

## 추가 의견
- 사람이 의심한 위치는 요청에 없음.
