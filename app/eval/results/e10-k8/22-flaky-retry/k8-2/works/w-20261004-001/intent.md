## 목표
CI 전용 시험 `ci/batch.test.js`가 가끔 `expected report-6 to belong to job-6, got job-5`로 실패하는 문제의 근본 원인을 찾아 고친다. 지연이 실제와 비슷한 환경에서 리포트가 엉뚱한 job에 묶이는 동작이 사라져야 한다.

## 비목표
- 시험에 재시도를 붙이거나 skip하거나 시간 제한을 늘리는 것 (해결이 아님)
- 배치를 순차 실행으로 되돌리는 것 (병렬 실행 동시 4개는 유지)
- 이번 실패와 무관한 리팩터링이나 기능 변경

## 원하는 결과
밤 배치를 어떤 지연 순서로 돌려도 각 report가 자기 job에 속한다. `npm run test:ci`가 반복 실행해도 안정적으로 통과한다.

## 완료조건
- [ ] 재현 절차가 더 이상 실패하지 않는다
- [ ] `npm run test:ci`가 통과한다
- [ ] 기존 테스트를 약화하거나 삭제하지 않는다
- [ ] `npm run test:ci`를 여러 번(예: 20회) 연속 실행해도 매번 통과한다
- [ ] `ci/batch.test.js`에 재시도, skip, 시간 제한 증가가 추가되지 않는다
- [ ] 배치 병렬 실행(동시 4개)이 유지되고 순차 실행으로 바뀌지 않는다

## 제약
- 로컬 `npm test`도 계속 통과해야 한다
- (사람) 배치 병렬 실행(동시 4개)은 유지해야 한다
