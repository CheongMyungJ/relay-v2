# fix: 제한 시간을 넘겨 성공한 발송을 실패로 보고 다시 보내던 중복 발송 수정

## 요약
느리게 성공한 메일·푸시·요약 발송이 시간 초과 실패로 처리되어 재시도로 한 번 더(최대 3통) 발송되던 문제를 고친다.

## 원인
`decide`가 성공 여부보다 걸린 시간을 먼저 봐서, 성공해도 `send.timeoutMs`를 넘으면 재시도했다. 요약의 `withDeadline`도 성공 뒤 시간 초과 오류를 던져 보낸 기록 없이 재시도했다. 응답이 느린 메일에서 더 잦았다.

## 변경
- `src/retry/policy.js`: 성공이면 시간과 무관하게 `done`. 실패일 때만 시간 초과 사유로 구분.
- `src/digest/deadline.js`, `runner.js`: 성공한 요약을 오류로 바꾸지 않고 `slow`일 때 경고 로그만 남김.
- 재시도 횟수·백오프 설정은 그대로이며 재시도를 끄지 않았다.

## 테스트
- `npm test` 81건 통과.
- 새 테스트 4건(메일·푸시·요약·decide)은 수정 전 코드에서 실패, 수정 후 통과. 실제 시간 초과 실패는 계속 재발송되는 테스트도 추가.
