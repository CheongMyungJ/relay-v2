# fix: 선물하기 적립도 배송비를 빼고 1P 미만은 버린다

## 요약
선물하기 주문 G-0213의 적립 예정 포인트가 고객센터 기준(218P)과 달리 249P로 나오던 문제를 고쳤다.

## 원인
`giftPoints`가 배송비가 포함된 `amounts.total` 전체에 반올림(`percentOf`)을 써서 일반 주문의 기준(배송비 제외, 1P 미만 버림)과 달랐다. 24,860원 × 1% = 248.6 → 249P (기준: (24,860 − 3,000) × 1% = 218.6 → 218P). 기존 테스트는 배송비 0에 딱 떨어지는 금액만 써서 드러나지 않았다.

## 변경
- `src/gift/gift-points.js`: `giftPoints`가 `earnPoints`를 쓰게 해 적립 기준을 한 곳으로 모았다.
- `test/gift.test.js`: G-0213 = 218P 테스트, 같은 입력의 일반 주문과 선물 주문 적립이 같은지 확인하는 테스트 추가.
- `docs/knowledge/points/earn-basis.md`: 선물하기도 같은 기준임을 규칙으로 옮김.
- 이미 저장된 `points.earned`는 재계산하지 않는다.

## 테스트
- `npm test`: 24개 모두 통과.
- 기준 커밋에서는 새 테스트 2건이 실패하고 수정 후 통과.
- G-0213 재현 명령 결과 `earned: 218`.
