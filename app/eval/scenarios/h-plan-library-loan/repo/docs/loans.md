# 도서 대출 설계

상태: 합의됨 (설계 PR 머지). 구현은 아래 "구현 나눔"의 조각 순서로 Work를 나눠 한다.

## 범위

책을 빌리고(대출), 돌려주고(반납, 연체료), 한 번 더 빌리는 것(연장)까지 한다. 예약, 회원 정지, 분실 처리는 이번에 하지 않는다.

## 자료

날짜는 모두 `'YYYY-MM-DD'` 문자열이고 도서관이 있는 곳의 달력 날짜다. 시각은 다루지 않는다. 함수는 "오늘"을 스스로 구하지 않고 `today`를 인자로 받는다.

대출 기록(loan):

| 필드 | 뜻 |
|---|---|
| `id` | `'L-0001'` 꼴. `nextLoanId()`로 얻는다 |
| `memberId`, `bookId` | 빌린 회원과 책 |
| `borrowedOn` | 빌린 날 |
| `baseDueOn` | 기준 기한. 휴관일을 따지기 전의 기한 |
| `dueOn` | 실제 반납 기한. 기준 기한이 휴관일이면 다음 개관일 |
| `renewals` | 연장한 횟수. 처음 0 |
| `returnedOn` | 반납한 날. 아직이면 `null` |
| `feeWon` | 연체료(원). 반납 전에는 `null` |

저장소는 읽으면 복사본을 주므로, 기록을 바꾼 뒤에는 `saveLoan`, `saveBook`으로 저장해야 한다.

## 인터페이스

`src/index.js`에서 내보낸다. 모두 날짜를 `today`로 받는다. 거절은 `LoanError`를 던지고 `code`로 까닭을 가른다.

- `checkout(memberId, bookId, today)`: 대출 기록을 만들어 저장하고 돌려준다.
- `returnBook(loanId, today)`: 반납을 처리하고 갱신된 기록을 돌려준다.
- `renewLoan(loanId, today)`: 연장하고 갱신된 기록을 돌려준다.

## 결정 표

| # | 결정 | 이유 |
|---|---|---|
| D1 | 대출 기간은 14일이다. `baseDueOn` = 대출일 + 14일. `dueOn` = `baseDueOn`이 휴관일이면 그 뒤 첫 개관일, 아니면 `baseDueOn` (`src/calendar.js`의 `nextOpenDay`) | 반납 창구가 닫힌 날을 기한으로 주면 안 된다 |
| D2 | 휴관일은 매주 월요일과 `src/config.js`의 `HOLIDAYS`다 | 달력이 한 곳에 있어야 한다 |
| D3 | 한 회원이 동시에 빌릴 수 있는 책은 5권이다(반납하지 않은 대출). 같은 책을 두 권 빌릴 수 없다 | 인기 책을 한 사람이 쌓아 두지 않게 |
| D4 | 연체 중인 대출이 하나라도 있는 회원은 새로 빌릴 수 없다. 연체는 `today > dueOn`이다(기한 당일까지는 연체가 아니다) | 연체를 풀고 빌리게 한다 |
| D5 | 책의 `available`이 0이면 빌릴 수 없다. 대출 때 1 줄고 반납 때 1 는다. 거절된 요청은 재고를 바꾸지 않는다 | 재고를 틀리지 않게 |
| D6 | 연체료는 연체일수 × 100원이고, 대출 한 건에 3,000원을 넘지 않는다. 연체일수는 `dueOn` 다음 날부터 반납일까지의 개관일 수다(휴관일은 세지 않는다). 반납은 휴관일에도 받는다(반납함) | 닫힌 날까지 벌금을 매기지 않는다 |
| D7 | 연체료는 반납할 때 한 번 정해 `feeWon`에 저장한다(연체가 없으면 0). 이미 반납한 대출을 다시 반납하면 거절하고 재고와 기록을 바꾸지 않는다 | 재고가 두 번 늘면 안 된다 |
| D8 | 연장은 대출당 1번이다. 새 `baseDueOn` = 현재 `baseDueOn` + 14일(연장하는 날 + 14일이 아니다). 새 `dueOn`은 D1처럼 새 `baseDueOn`에서 휴관일을 미룬 날이다. 휴관 때문에 미뤄 준 날은 연장 기간에 쌓이지 않는다 | 연장을 일찍 하든 늦게 하든 같은 날까지 빌리게 하고, 휴관으로 얻은 하루가 계속 불어나지 않게 |
| D9 | 연체 중인 대출(`today > dueOn`)과 이미 반납한 대출은 연장할 수 없다. 연장은 재고와 회원의 대출 권수, 대출 번호, 대출일을 바꾸지 않는다 | 연장은 새 대출이 아니다 |
| D10 | 거절 코드: 없는 회원·책·대출 `NOT_FOUND`, 재고 없음 `NO_COPIES`, 5권 초과 `LIMIT`, 같은 책 `DUPLICATE`, 연체 중 `OVERDUE_BLOCK`, 이미 반납 `ALREADY_RETURNED`, 연장 1번 초과 `RENEW_LIMIT`, 연장 때 연체 `OVERDUE` | 호출하는 쪽이 까닭별로 안내한다 |
