# shop

작은 온라인 상점의 서버 쪽 코드다. 영역은 셋이다.

- 주문(`src/orders/`): 장바구니, 금액 계산(쿠폰, 배송비), 주문의 생애(접수, 결제, 배송, 취소)
- 청구(`src/billing/`): 결제 대행, 송장, 반품 전표, 입금, 명세서, 연체
- 알림(`src/notifications/`): 메일과 문자, 방해 금지 시간, 수신 거부

상품(`src/catalog/`)과 고객(`src/customers/`)은 세 영역이 같이 쓴다. `src/index.js`의 `createShop()`이 모두를
엮는다. 저장소는 메모리이고 시계는 `src/clock.js`로 바꿀 수 있다(시험에서 시간을 옮긴다).

금액은 원 단위 정수이고 상품 가격은 부가세를 포함한다. 시각은 UTC로 두고, 사람에게 보이는 날짜와 시간은 한국 시간이다.
