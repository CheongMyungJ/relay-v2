# shop

숲결마켓(식품·생활용품 온라인 몰)의 주문 모듈. 주문 금액과 배송비, 쿠폰, 포인트 적립·사용·회수, 환불, 선물하기 주문, 영수증 글자를 만든다.

## 도메인

- **주문:** 고객 하나에 주문 줄 여러 개(단가 × 수량). 만들 때 금액(`amounts`)과 적립 포인트(`points.earned`)를 계산해 저장하고, 그 뒤 영수증·환불·포인트 내역은 저장된 값을 쓴다.
- **쿠폰:** 주문 하나에 하나. 금액 할인 또는 비율 할인(10원 단위 버림, 최대 할인).
- **배송비:** 3,000원. 쿠폰을 뺀 상품 금액이 30,000원 이상이면 무료.
- **포인트:** 1P = 1원. 주문할 때 결제에 쓸 수 있고(1,000P부터, 10P 단위), 주문하면 적립된다. 적립률은 `src/config.js`의 `POINT_RATE_PERCENT`. 적립한 날부터 365일 뒤에 사라진다.
- **환불:** 부분 환불은 돌려받는 상품 금액을 돌려주고 적립했던 포인트 일부를 회수한다. 전체 취소는 모두 돌려놓는다.
- **선물하기:** 보내는 사람이 결제하고 받는 사람에게 보내는 주문(`G-0213`). 메시지 카드를 넣을 수 있고, 적립 포인트는 보내는 사람에게 쌓인다.
- **금액:** 모두 정수 원.

## 구조

```
src/
  config.js            배송비, 포인트 적립률·유효 기간, 번호 형식
  money.js             원 단위 금액 도우미
  cart/                주문 줄, 쿠폰
  orders/              주문 금액, 배송비, 환불
  points/              적립, 사용 검사, 포인트 내역(잔액, 소멸)
  gift/                선물하기 주문과 그 적립
  format/              영수증 글자(앱과 메일이 그대로 보여 준다)
  cli.js               주문 JSON으로 영수증 찍어 보기
examples/              문의가 들어온 주문의 입력 데이터 사본, 환불 요청
```

## 쓰기

```sh
npm test
node src/cli.js examples/O-1042.json
node src/cli.js examples/G-0213.json
node src/cli.js examples/R-0311.json --order examples/O-1077.json
```

`src/format/receipt.js`의 출력은 앱과 주문 확인 메일이 줄 단위로 그대로 보여 준다. 칸 너비나 줄 차례를 바꾸면 화면이 어긋난다.
