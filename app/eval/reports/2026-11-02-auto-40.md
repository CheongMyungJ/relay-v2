A는 코드가 더 짧다. parseKrw에서 "-₩0"이 -0이 되지 않게 처리했고, 기호 사이 공백도 받는다. 다만 코드가 빽빽하다. formatKrw에 NaN 같은 값을 넣으면 "₩NaN"이 나온다. 시험은 왕복, 빈 글, 공휴일을 다루지만 경계 사례는 B보다 적다.

B는 코드가 더 읽기 쉽다. parseCsv는 한 줄에 한 동작으로 풀어 썼고, workdays는 isWorkday 같은 보조 함수로 나눴다. 각 함수에 주석이 있고, parseKrw에서는 안전하지 않은 정수를 걸러 null로 돌려준다. 시험은 더 넓다. 공휴일 중복, 월·연 경계, 시작일과 끝일이 같은 경우, 큰 음수 왕복, 끝 줄바꿈, 단일 칸 행까지 다룬다. 약점은 parseKrw("-₩0")이 -0을 돌려주는 것이다. 또 formatKrw가 요청에 없는 TypeError를 던지고, 반복문 조건에서 toMs(end)를 매번 다시 계산한다.

B가 시험 범위와 가독성에서 조금 앞서고, A는 -0 처리와 변경 범위에서 앞선다. 종합하면 B를 근소하게 우세로 본다.
  - 경험 전체 cli (relay (자율 유형) 6, 맨 CLI 7) — A는 한 번 요청으로 1.4분에 끝났고 수고가 매우 적었다. 다만 규칙을 묻지 않아 수정이 한 번 필요했고 코드를 확인하지 못했다. B는 사전 질문, 판정표, diff 확인으로 통제와 확신이 나았다. 하지만 14차례, 5.2분, 진행 표시 없는 긴 대기가 부담이었다. 수고와 시간 차이가 커서 A를 약간 앞서게 봤다.

### 사람 역할의 말

- [relay#1 좋음] 단계마다 판정표와 전체 변경 diff를 보여 줘서 코드와 테스트를 믿고 승인할 수 있었다. 경계 사례도 물어봐 주고, 내 지시(소수 버림, 왕복)를 설계와 구현에 정확히 반영했다.
- [relay#1 불편] 세 가지를 한 번에 맡기고 모듈별 브랜치도 원했는데, 첫 Work는 의도 정리 단계에서 막혀 포기해야 했다. 초안 카드로 Work를 하나씩 직접 만들고 포기 체크를 신경 쓰는 과정이 번거로웠다.
- [relay#2 좋음] 모듈마다 브랜치를 따로 두고 싶다고 쓴 것을 에이전트가 의도 정리에서 알아채고 Work 세 개로 나누자고 먼저 제안했다. 판정표와 diff로 결과를 확인하기도 쉬웠다.
- [relay#2 불편] 초안을 새 Work로 만들 때 '원래 Work 포기'가 기본으로 켜져 있어, 그대로 뒀다면 csv Work가 사라질 뻔했다. Work 세 개를 오가며 승인 버튼을 일일이 눌러야 하는 것도 번거로웠다.
- [cli#1 좋음] 한 번 요청으로 세 모듈을 모듈별 브랜치에 나눠 커밋해 줬고, 임의로 정한 부분을 요약에 적어 줘서 어긋난 점을 바로 짚을 수 있었다.
- [cli#1 불편] 양 끝 포함, 소수 버림 같은 세부 규칙을 묻지 않고 마음대로 정해서 한 번 더 고쳐 달라고 해야 했다. 코드 diff는 직접 보지 않았다.
- [cli#2 좋음] 한 번 요청으로 세 모듈이 모듈별 브랜치와 테스트까지 갖춰 나왔고, 정한 사항을 요약에 정리해 줬다.
- [cli#2 불편] formatKrw 반올림처럼 물어봐야 할 규칙을 묻지 않고 정해서 나중에 내가 바로잡아야 했다. 코드는 직접 확인하지 않았고 요약에 의존했다.
- [relay@auto#1 좋음] 모듈별 브랜치를 따로 두고 싶다는 선호를 에이전트가 먼저 짚어 Work 3개로 나누자고 제안했다. 판정표와 독립 리뷰, 완료조건별 근거가 있어 결과를 믿기 쉬웠다.
- [relay@auto#1 불편] Work를 나눈 뒤 초안 카드 3개를 하나씩 새 Work로 만들어야 했고 '원래 Work 포기' 체크도 직접 챙겨야 했다. 한 번에 맡겼는데 손이 꽤 갔다. money Work에는 완료조건 하나가 지식 문서 때문에 실패로 찍혀, 코드 문제가 아닌데도 헷갈렸다.
- [relay@auto#2 좋음] 한 번 요청으로 세 모듈이 모듈별 브랜치 3개로 나뉘어 만들어졌다. 의도 정리에서 브랜치 분리 방식과 근무일 경계 규칙을 물어 줬고, 판정표로 완료조건별 통과 근거를 볼 수 있었다.
- [relay@auto#2 불편] 의도 승인 뒤 독립 리뷰가 도는 동안 터미널이 비어 있고 진행을 알기 어려워 기다리기만 했다. 의도 초안이 길어 경고(분량 초과)가 뜬 점도 아쉬웠다.
