# Claude Code CLI 사용법 (요약)

터미널에서 claude를 실행하면 대화형 세션이 열린다. 평가는 레포 폴더에서 claude가 이미 실행된 상태로 시작한다.

- 요청을 입력하고 Enter를 누른다. 에이전트가 파일을 읽고 고치고 명령을 실행한다(권한 확인 없이 실행하는 모드).
- 에이전트가 선택지로 질문하면 방향키와 Enter(또는 숫자)로 고르거나 글로 답한다.
- 에이전트가 일하는 중에 Esc를 누르면 멈춘다. 멈춘 뒤 새 지시를 할 수 있다. 일하는 중에 입력한 말은 다음 차례에 전달된다.
- Shift+Tab으로 계획 모드로 바꾸면 고치기 전에 계획만 세우게 할 수 있다.
- 커밋은 에이전트에게 시키거나("커밋해 줘") 직접 한다. 입력 앞에 !를 붙이면 셸 명령을 바로 실행한다(예: `!git status`, `!git diff`).
- `/clear`로 대화를 비우고, `/exit`나 Ctrl+C 두 번으로 끝낸다.
- 셸에서 `claude --continue`는 이 폴더의 마지막 대화를 이어서 열고, `claude --resume`은 지난 대화 목록에서 골라 연다. 평가에서 claude를 새로 띄울 때는 `claude --dangerously-skip-permissions`에 이 인자들을 붙인다.
- 다른 일을 나란히 하려면 새 터미널을 열어 claude를 따로 실행한다. 같은 폴더에서 동시에 고치면 변경이 섞일 수 있으므로 필요하면 브랜치나 git worktree로 나눈다.
